# 🌦️ Consulta del Clima — OpenWeather API  

Una aplicación web sencilla que permite consultar el clima actual de cualquier ciudad del mundo utilizando la **API de OpenWeatherMap**.  
El usuario solo debe ingresar el nombre de la ciudad, y la app mostrará la **temperatura**, **condiciones del clima** y una breve **descripción meteorológica** en tiempo real.

---

## 📋 Características  

- 🔍 Consulta el clima actual ingresando el nombre de la ciudad.  
- 🌡️ Muestra la temperatura en grados Celsius.  
- ☁️ Incluye una descripción detallada del clima (por ejemplo, "nublado", "soleado", "lluvioso").   
- ⚡ Conexión directa a la **API pública de OpenWeatherMap**.
